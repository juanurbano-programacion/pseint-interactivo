1. Introducción a Algoritmos, Variables y Tipos de Datos

Un algoritmo es un conjunto finito, ordenado y secuencial de instrucciones lógicas diseñadas para resolver un problema determinado. En el entorno de PSeInt, utilizamos pseudocódigo en español, lo que nos permite entrenar nuestra lógica algorítmica sin pelearnos con las barreras lingüísticas de lenguajes complejos.

Para procesar información, necesitamos recurrir a las variables. Una variable es, técnicamente, un espacio reservado en la memoria RAM de la computadora donde guardamos un dato que puede transformarse durante la ejecución de nuestro programa. En configuraciones de perfil estricto, es fundamental declarar el tipo de dato antes de usarlo.

Tipos de Datos Soportados

  • Entero: Valores numéricos exactos, sin componentes decimales (ej. 25, -100).
  • Real: Números que incluyen precisión decimal (ej. 3.1416, 0.75).
  • Caracter / Cadena: Texto, letras, palabras o símbolos envueltos entre comillas dobles (ej. "Juan", "A").
  • Logico: Variables booleanas que solo aceptan dos estados posibles: Verdadero o Falso.

2. Estructuras de Control Condicionales (Si-Entonces)

Los algoritmos planos se ejecutan de manera lineal, de arriba hacia abajo. Sin embargo, para dotar de inteligencia a un sistema, requerimos la toma de decisiones. La estructura Si-Entonces-Sino evalúa una condición lógica (una pregunta): si dicha condición se cumple (es Verdadera), toma un camino; si no se cumple (es Falsa), toma un desvío alternativo.

3. Estructuras Cíclicas o Repetitivas (Mientras y Para)

Uno de los superpoderes de las computadoras es la capacidad de repetir una tarea millones de veces sin cansarse ni cometer errores. En PSeInt utilizamos estructuras como el Mientras (While) y el Para (For) para controlar bucles.

El bucle Mientras evalúa una condición en cada vuelta. El bloque interno de instrucciones se ejecutará repetidamente mientras esa condición siga dando como resultado Verdadero. Es el mecanismo ideal para validar que el usuario ingrese datos correctos.

Ejemplo de Código Limpio: Validación Indefinida

Algoritmo ValidarPin
    Definir pin Como Entero;
    
    Escribir "Ingrese su código de seguridad de 4 dígitos:";
    Leer pin;
    
    // Si el PIN no es el correcto, lo encierra en el bucle
    Mientras pin <> 9912 Hacer
        Escribir "PIN incorrecto. Acceso denegado. Intente de nuevo:";
        Leer pin;
    FinMientras
    
    Escribir "¡Acceso Concedido de forma segura!";
FinAlgoritmo

Caso Resuelto: Liquidación de Sueldos con Horas Extras

Algoritmo CalcularSueldoNeto
    Definir horasTrabajadas, horasExtras Como Entero;
    Definir valorHora, sueldoBruto, retenciones, sueldoNeto Como Real;
    
    Escribir "Cantidad de horas mensuales trabajadas:";
    Leer horasTrabajadas;
    Escribir "Valor monetario de la hora base:";
    Leer valorHora;
    
    Si horasTrabajadas <= 40 Entonces
        sueldoBruto <- horasTrabajadas * valorHora;
    Sino
        horasExtras <- horasTrabajadas - 40;
        sueldoBruto <- (40 * valorHora) + (horasExtras * valorHora * 2);
    FinSi
    
    retenciones <- sueldoBruto * 0.11; // Descuento del 11% por jubilación
    sueldoNeto <- sueldoBruto - retenciones;
    
    Escribir "Sueldo Bruto calculado: $", sueldoBruto;
    Escribir "Sueldo Neto final a cobrar en mano: $", sueldoNeto;
FinAlgoritmo
